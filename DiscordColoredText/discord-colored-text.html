What gets copied

Discord shows colours inside an ansi code block, so keep “Wrap in a code block” on when pasting into a normal message. Colours show on Discord desktop and the web, and some mobile apps may show the raw codes instead. The preview colours and backgrounds are close to Discord’s but not exact. This is an unofficial tool.
