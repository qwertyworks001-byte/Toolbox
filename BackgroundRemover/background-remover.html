This tool uses @imgly/background-removal, an open-source AI model (AGPL-3.0 licensed) that runs entirely on your device via WebAssembly — your images are never sent to a server. The first run downloads the model itself, which your browser then caches, so later runs are much faster. Images are processed one at a time to keep your browser responsive, and a cleanup pass patches small interior "holes" the AI sometimes leaves on flat-colored or low-contrast subjects. Each image uses whichever Speed/Quality mode was selected when it was added. Worth knowing: this is a general-purpose open-source model, not the specialized, purpose-trained one a paid service like remove.bg runs on a server — on some images (especially flat, cartoon-style, or low-contrast ones) it just won't be as clean, and there's no config tweak here that fully closes that gap.
